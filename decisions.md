# Decisions

- **Edit scope:** viewer + AI only. Keep tokens/variables and components. (2026-11-20)
- **Rendering:** native AppKit canvas + one WKWebView per artboard, snapshot/suspend when offscreen or zoomed out. (2026-11-20)
- **Claude IO:** MCP server + plain project files. (2026-11-20)
- **Location:** ~/Desktop/Canvas, app name "Canvas". (2026-11-20)
- **Components:** custom tags + props/slots. (2026-11-20)
- **Tokens:** CSS vars + modes. (2026-11-20)
- **Presentation:** single board only. (2026-11-20)
- **Animations:** any CSS/JS in the HTML, plus play/pause/restart controls and auto-pause. (2026-11-20)
- **Extra UI scope:** pages, document tabs (+ Dashboard), Connect agent button. No per-page canvas background. (2026-11-20)
- **Look:** dark layout in the style of Paper, with our own styling. (2026-11-20)
